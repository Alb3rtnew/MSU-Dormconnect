# MSU DormConnect — Login Page 

A polished and fully responsive login and sign-up interface 
for the MSU DormConnect platform, built using pure HTML and 
CSS. This version features an upgraded two-panel layout with 
smooth animations, role-based login selection (Student and 
Dorm Owner), and a modern design using custom Google Fonts 
and a maroon-themed color palette inspired by MSU's branding.

## Technologies Used
- HTML5
- CSS3 (custom animations, CSS variables, flexbox)
- Google Fonts (Playfair Display, DM Sans, DM Mono)

## Features
- Animated two-panel layout (slide-in on load)
- Login and Sign-Up tab switching
- Role-based selection — Student or Dorm Owner
- Floating glow orb background effects
- Hexagonal background pattern
- Fully styled form inputs with focus states
- Responsive design for different screen sizes

## How to Run
1. Clone or download the repository
2. Open `msu-dormconnect-login.html` in any web browser
3. No installation or dependencies required
